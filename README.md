# Shop Management

GitHub Pages-ready mobile web app.

Features:
- Customer name
- Withdrawal (1% commission)
- Money Transfer (1.5% commission)
- Recharge (0% commission)
- Daily report
- Monthly profit
- Opening and closing balance
- Transaction history with customer, date and time
- No Aadhaar number field
- Browser localStorage

## GitHub Pages
Upload `index.html` to a public repository and enable:
Settings -> Pages -> Deploy from a branch -> main -> / (root).

Note: data is stored in the browser's localStorage and is not automatically shared between devices.
